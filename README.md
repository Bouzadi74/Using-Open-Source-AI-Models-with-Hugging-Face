In this project, I explored the Hugging Face ecosystem by using pre-trained models for a variety of tasks, including text classification, language translation, and image captioning. I learned how to load and work with different model types such as AutoModel, AutoModelForSequenceClassification, and BlipForConditionalGeneration, and built simple pipelines for NLP and computer vision tasks. The project highlights the practical use of open-source models to perform inference and generate meaningful outputs from both text and images.
